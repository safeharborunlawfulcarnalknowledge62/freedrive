## ⚙️ Running the Software

You do not need to install complex programs. FreeDrive consists of a single file. 

1. Locate the file you downloaded. 
2. Double-click the file to open it.
3. Windows may show a security window. Click "More info" and then "Run anyway" if it appears.
4. A black terminal window opens. This window keeps the server running. Do not close this window while you use FreeDrive.
5. Open your web browser. Type `http://localhost:8080` in the address bar and press Enter.

You see the login screen. The first time you launch the software, it prompts you to create an administrator account. Enter your email and choose a strong password. This account manages all other users and file permissions.

## 💡 Frequently Asked Questions

**Does the software work offline?**
You need a connection to the computer running the software to access your files. If you run it on your home laptop, you need your wireless network to reach the files from another device.

**How do I stop the service?**
Simply close the black terminal window. The software shuts down immediately. Your data remains safe on your hard drive. Open the file again whenever you need to access your storage.

**Can I access my files away from home?**
Yes, but you must configure your network router to allow traffic to your computer. This process involves port forwarding. Refer to your router manual for instructions on opening port 8080. This step is optional and only necessary for remote access.

**What happens if my computer loses power?**
FreeDrive stops working when the computer shuts down. When you start your computer again, double-click the file to restart the service. Your data stays fully intact.

**Is my data backed up?**
FreeDrive stores files as they are on your disk. You should back up the folder where you keep your FreeDrive data. Use an external hard drive or another backup tool to duplicate your files periodically. This protects you against hardware failure.
